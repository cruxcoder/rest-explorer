# Product Requirements Documents

These PRDs define the planned feature set for each RestX release. They were created as "destination documents" during the AI-assisted planning phase before implementation.

| Version | Focus | Status |
|---------|-------|--------|
| v1.0 | Core — DSL engine, spec loading, REPL, curl generation | Implemented |
| v1.1 | Interactive split-pane viewer | In progress |
| v1.2 | UX polish — curl output, schema expansion, search | Planned |
| v1.3 | Command unification, shell integration, pager | Planned |
| v1.4 | Prompt positioning, status line, pager stability | Planned |

> **Note:** These documents describe the *intended* design, not necessarily the current state of the code. As implementation progresses, some details may diverge from the original PRD.
